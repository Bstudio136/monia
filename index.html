DeepChat

DeepChat est un client de chat multi-fournisseurs (multi-provider AI) qui vous permet de discuter avec différents modèles d'intelligence artificielle (OpenAI, Groq, Mistral, Gemini, Hugging Face, Agnes) depuis une interface unique. Il supporte le streaming, le raisonnement (reasoning), la génération d'images, le rendu Markdown, la coloration syntaxique, les pièces jointes, et bien plus encore. Toutes les données (conversations, clés API) sont stockées localement dans votre navigateur pour une confidentialité maximale.
